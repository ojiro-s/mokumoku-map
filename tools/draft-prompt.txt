この動画で紹介されているスモークの定点を、下の形式の JSON 配列で書き出してください。
JSON 以外の文章やコードブロックの記号は付けず、配列だけを出力してください。

## 1件の形

{"map": "ascent", "agent": "Omen", "side": "attack", "site": "A", "purpose": "entry",
 "title": "Aメインを焚く", "comment": "照準の合わせ方などのコツ", "start": 75, "source": "動画の投稿者名",
 "points": [{"targetCallout": "A メイン", "standCallout": "アタック側 スポーン"}]}

## 各項目の書き方

- map：下の「マップ一覧」の slug（英小文字）。動画に複数のマップが出てくる場合は、定点ごとにそのマップを書きます。
- agent：次のどれか。どのエージェントでも使える定点は All にします。
{{AGENTS}}
- side：次のどれか。
{{SIDES}}
- site：そのマップの site のどれか（マップ一覧を参照）。中央の定点は Mid にします。
- purpose：次のどれか。
{{PURPOSES}}
- title：何を焚くかを短く日本語で（例：Aショートを焚く）。
- comment：照準の合わせ方、立ち位置、投げ方などのコツを日本語で。分からなければ空文字。
- start：その定点の説明が始まる動画の秒数（整数）。
- source：動画の投稿者名やチャンネル名。
- points：同時に焚くスモークを1つずつ並べます。1つだけなら要素は1つです。
  - targetCallout：スモークが落ちる場所の名前。
  - standCallout：投げる人が立つ場所の名前。分からなければ null。
  - 場所の名前は、そのマップの「場所の名前」の表記どおりに書きます（括弧内の英語名でも構いません）。
    ちょうど合う名前がないときは、いちばん近い名前を選んでください。
- id と patch は書かないでください。
